Uma coleção de loaders animados com **efeito líquido** usando filtros SVG e CSS puro. Perfeito para dar um toque moderno e orgânico aos seus projetos!

## ✨ Demonstração

[🔗 Ver Demo](https://seu-usuario.github.io/liquid-loader-variations)

## 🎨 Variações Disponíveis

| Variação | Descrição | Tecnologias |
| -------- | --------- | ----------- |
| **🔄 Circle** | Gotas orbitando em círculo com efeito líquido | SVG Filter, CSS Animations |
| **🌊 Wave** | Ondas horizontais com movimento fluido | SVG Filter, CSS Flexbox |
| **💧 Drop** | Gotas caindo em cascata | SVG Filter, CSS Keyframes |
| **🌀 Morph** | Formas que se transformam organicamente | SVG Filter, CSS Border-Radius |
| **✨ Spiral** | Espiral hipnótica em movimento | SVG Filter, CSS Transform |

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Animações, transições e estilização
- **SVG Filters** - `feGaussianBlur` + `feColorMatrix` para efeito líquido
- **CSS Variables** - Controle dinâmico de delays e cores
- **Responsive Design** - Adaptação para todos os dispositivos
