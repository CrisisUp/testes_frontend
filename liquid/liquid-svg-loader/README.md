# 💧 Liquid Loader

Loader animado com efeito líquido usando filtros SVG e CSS puro.

## ✨ Demonstração

[Link para demo ao vivo]

## 🛠️ Tecnologias

- HTML5
- CSS3 (Animações, Filtros)
- SVG (feGaussianBlur, feColorMatrix)

## 🎯 Características

- ✅ Efeito líquido orgânico
- ✅ Cores dinâmicas (hue-rotate)
- ✅ Animação em cascata
- ✅ Responsivo
- ✅ Acessível (prefers-reduced-motion)
- ✅ Sem JavaScript

## 📱 Compatibilidade

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

## 🚀 Como usar

1. Clone o repositório
2. Abra o index.html no navegador
